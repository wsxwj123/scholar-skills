# 课题库格式

课题库是本技能唯一的持久产物：一条课题一个 Markdown 文件，由 AI 写入，用户在文本编辑器或 Obsidian 中直接阅读与修改。本文件定义库的位置、文件名、frontmatter 字段与正文结构。

## 一、库的位置

配置写在 `~/.idea-bomb/config.json`。该文件已被 `zotero_read.py` 使用，在其中增加两个键即可，不另建配置文件：

```json
{
  "zotero_data_dir": "……",
  "vault_dir": "/绝对路径/到/Obsidian vault 根目录",
  "ideas_subdir": "课题思路"
}
```

- 两个键齐备，且 `vault_dir` 指向的目录存在 → 课题库目录为 `<vault_dir>/<ideas_subdir>/`。
- 任一键缺失或路径不存在 → 课题库目录为 `~/.idea-bomb/ideas/`。

默认路径是普通目录，不依赖 Obsidian。未安装 Obsidian 的用户功能完整，仅缺 dataview 总表与双链两项便利。

**AI 的硬规则**：只读 `config.json` 判断，读不到文件或键不存在即用默认路径。不得猜测 vault 位置，不得扫描文件系统寻找 `.obsidian`，不得为此中断工作或反复追问。首次向默认路径写入时以一句话告知用户可通过上述两个键把库改到 vault 内，此后不再提示。

目录不存在时直接创建。

## 二、文件名

`IB-<四位序号>-<短标题>.md`，例 `IB-0031-EET当可寻址控制总线.md`。

- 序号全局单调递增，自 `IB-0001` 起，永不复用。新建前列目录取最大序号加一。
- 短标题取自 `标题` 字段，不超过 20 字，去除 `/ \ : * ? " < > | #` 与换行。
- frontmatter 须写 `aliases: [IB-0031]`。双链一律写 `[[IB-0031]]`，AI 定位文件一律用通配符 `IB-0031-*.md`。用户在 Obsidian 中改标题或改文件名均不断链。
- 序号冲突不设锁。两个会话同时取到同一序号时短标题不同，结果是两个文件而非互相覆盖，发现后改其中一个的序号即可。
- 不用日期命名：同日常产出多条，日期需再附序号，等于维护两套 ID；且按 ID 定位只需一次通配符匹配，按日期定位须先知道是哪天。年代信息由 `日期` 字段承担。

## 三、frontmatter

判据：**用于筛选与排序的短值进 frontmatter，成段的论述进正文。**

必填五项加 tags：

| 键 | 取值 | 说明 |
|---|---|---|
| `id` | `IB-0031` | 与文件名序号一致 |
| `aliases` | `[IB-0031]` | 双链锚点，仅此一个元素 |
| `标题` | 一句名词短语 | 不超过 20 字，与文件名的短标题一致 |
| `日期` | `2026-09-24` | 建档日期 |
| `裁决` | `采纳` / `否决` / `归档` | 仅此三值，**无裁决不建档** |
| `tags` | `[课题思路, idea-bomb]` | 可追加领域标签 |

选填，有则写，无则整键不出现：

| 键 | 取值 | 说明 |
|---|---|---|
| `裁决日期` | `2026-09-24` | 裁决与建档同日时可省 |
| `创新性` | `高` / `中` / `低` | 仅此三值。程度上的细微差别写进正文 `## 查新`，不在此处造中间档 |
| `可行性` | `高` / `中` / `低` | 同上，细节写进正文 `## 可行性` |
| `方法` | `transfer` / `combine` / `angle` / `contradiction` / `problem` / `tech_mismatch` / `data_driven` / `failure` | 只填一个。混用多种方法时取主导者，其余在正文说明 |
| `状态` | `untried` / `done` / `failed` | 缺省视为 `untried` |
| `平台` | 短名词，如 `工程化细菌` | 课题落点的体系或平台。不超过 12 字，含标点则改写或省略 |
| `疾病` | 短名词，如 `实体瘤` | 非生物医学领域省略此键 |
| `源领域` | 短名词，如 `心血管介入` | 跨界迁移类课题填写 |
| `源机制` | 短名词短语，不超过 20 字 | 机制的展开说明写进正文 `## 研究背景` |

不设 `象限` 字段。甜区即 `创新性: 高` 与 `可行性: 高` 的交集，两个字段直接筛得出；单列一个派生字段只会与它们互相矛盾。

### YAML 书写硬规则

- 值一律单行，不换行。
- 值中含 `: # [ ] { } " ' | > % @ &` 或以数字开头时，整体用双引号包起来；值内原有的双引号改为单引号或删除。
- 列表用行内形式 `[a, b]`。

一个未转义的冒号即可让整条笔记从所有 dataview 视图中消失，且 Obsidian 不报错、不提示。这是 Markdown 存储相较于 JSON 新增的真实风险，写入前逐值检查。

## 四、正文结构

小标题与顺序固定。**缺失的章节整节不出现，不写 `—`、`待补` 一类占位符。** 用户删掉了某节时按没有处理，不回填、不改写用户写下的内容。

| 小标题 | 内容 | 何时出现 |
|---|---|---|
| `# IB-0031 <标题>` | 一级标题 | 必有 |
| `## 一句话` | 种子原句扩写，说清课题是什么，不少于 30 字 | 必有 |
| `## 研究背景` | 假说四要素之一 | 必有 |
| `## Gap` | 假说四要素之一 | 必有 |
| `## 研究思路与设计` | 假说四要素之一 | 必有 |
| `## 创新点` | 假说四要素之一 | 必有 |
| `## 实验设计` | 最小实验方案：假设、关键对比、读出指标、对照、可行性瓶颈 | 仅用户明确要求时 |
| `## 可行性` | 三层逐行 `- 机制：…` `- 体系实现：…` `- 三年立项：…`；其后另起段落写瓶颈；可行性判为低时再写翻盘条件 | 必有 |
| `## 查新` | 检索式、最接近工作、差异点 | 必有 |
| `## 证伪点` | 承重变量加非同义反复的阴性对照 | 必有 |
| `## 裁决` | 用户裁决的原话转述；判为归档时下设 `### 重启条件` | 必有 |
| `## 参考文献` | 正文编号引用对应的条目，每条含作者、期刊、年份、PMID 或 DOI | 正文出现编号引用时必有 |
| `## 来源` | 触发本课题的输入材料。文献逐行写 `- 标题:` `- DOI:` `- 笔记:` 等，有哪项写哪项，值不截断 | 有明确输入材料时 |

四要素的文体要求见 `hypothesis-format.md`：段落式叙事，禁止用条目列表展开论述，论断附编号引用。`## 可行性` 的三层与 `## 来源` 的题录属于登记项而非论述，用条目行书写。

`## 来源` 中的文献若在 vault 内已有笔记，写 `- 笔记: [[笔记文件名]]` 形成双链；查不到就写明文题录，不猜测笔记名。

## 五、完整示例

````markdown
---
id: IB-0007
aliases: [IB-0007]
标题: "肿瘤支配神经的不可逆去神经干预"
日期: 2026-09-24
裁决: 采纳
创新性: 高
可行性: 中
方法: transfer
状态: untried
平台: 纳米载体
疾病: 实体瘤
源领域: 心血管介入
源机制: 经导管肾动脉去神经术
tags: [课题思路, idea-bomb]
---

# IB-0007 肿瘤支配神经的不可逆去神经干预

## 一句话

将心血管介入领域一次性完成的去神经术引入实体瘤治疗，以纳米载体把长效神经阻断剂靶向递送至肿瘤支配神经，用单次干预取代现有可逆阻断所需的反复给药。

## 研究背景

经导管肾动脉去神经术通过消融肾交感神经实现持久降压，单次操作即可获得长期疗效，已在难治性高血压中获得临床验证[1]。肿瘤神经支配的干预目前仍以可逆性阻断为主，如普萘洛尔脂质体递送，需反复给药方能维持效应[2]。本研究拟将持久性去神经策略引入实体瘤治疗，以纳米载体靶向递送长效神经阻断剂至肿瘤支配神经，建立不可逆的肿瘤去神经干预手段。

## Gap

既往研究未开展针对肿瘤支配神经的不可逆干预，现有手段均依赖药物浓度维持，停药后神经功能恢复。

## 研究思路与设计

在皮下与原位荷瘤模型中比较单次给予的长效阻断制剂与反复给予的可逆阻断剂，读出指标为瘤内神经纤维密度、去甲肾上腺素水平与肿瘤生长曲线，并以正常组织的神经支配完整性作为选择性的判定依据。

## 创新点

把神经干预从需要维持的药理学阻断转为一次完成的结构性阻断，使肿瘤神经支配成为可一次性移除的变量。

## 可行性

- 机制：肾动脉去神经术依赖交感神经在血管外膜的集中走行，肿瘤支配神经的解剖分布是否具备同等的可及性尚待确认，机制迁移存在前提。
- 体系实现：长效阻断剂的载体包封与瘤周滞留在现有制剂平台上可实现，难点在于神经与肿瘤实质的空间分辨。
- 三年立项：动物模型与读出指标均为现有条件，三年内可完成概念验证。

瓶颈在于作用选择性，须先证实该策略特异性作用于肿瘤支配神经而不损伤正常组织神经支配。

## 查新

检索式：tumor denervation nanoparticle sustained；renal denervation catheter-based long-term。

最接近工作：<真实检索命中的一篇，写作者、期刊、年份与 PMID 或 DOI>

差异点：既有工作以可逆阻断为主，本方向的干预不可逆且以单次给药完成。

## 证伪点

承重变量是肿瘤支配神经的功能性输入。以神经完整而仅给予空白载体的组作为阴性对照，若阻断组与对照组的肿瘤生长曲线无分离，则本假设被证伪。

## 裁决

采纳。用户判断选择性验证的路径清楚，先做安全性边界再推进疗效。

## 参考文献

[1] 作者. 期刊. 年份. PMID 或 DOI
[2] 作者. 期刊. 年份. PMID 或 DOI

## 来源

- 标题: <输入文献题名>
- DOI: <输入文献 DOI>
- 笔记: [[2026-09-15_Tumor_innervation]]
````

示例中以尖括号标出的文献标识为格式占位，实际写入必须是真实检索所得。禁止为凑格式编造文献。

## 六、总表（仅在库位于 vault 内时有意义）

在 vault 中与课题库目录同级建一个 `课题库总表.md`，供用户在 Obsidian 里筛选全库：

`````markdown
```dataview
TABLE WITHOUT ID link(file.link, 标题) as 课题, 裁决, 创新性, 可行性, 方法, 日期
FROM "课题思路"
WHERE id
SORT 日期 DESC
```

## 待裁决（应为空）

```dataview
LIST FROM "课题思路"
WHERE id AND 裁决 != "采纳" AND 裁决 != "否决" AND 裁决 != "归档"
```
`````

`FROM` 后的路径须改成实际的课题库目录名，写法为 vault 内的相对路径。总表需要 dataview 插件；未装插件时两个代码块原样显示，不影响课题文件本身。

**陷阱：dataview 在渲染时才执行。** AI 用文本方式读这个文件只会看到代码块本身，看不到任何查询结果。**总表是给人看的，AI 查库必须走 SKILL.md 中 Step 0 的 `find` 命令。** 读过总表不等于读过全库，把它当成库快照会导致重复推荐已否决的课题。

## 七、人工验收

新装本技能或改动本格式后跑一遍，约五分钟：

1. 按上述格式手写一个 `IB-0001-验收用例.md`，`裁决` 写 `否决`。
2. 检查文件名形如 `IB-0001-<短标题>.md`；在 Obsidian 中打开，确认 frontmatter 被识别为属性面板而非正文文本。
3. 打开总表，确认这一行出现在表中，且不出现在“待裁决”视图里。
4. 把 `裁决` 改成 `待定`，跑 Step 0 的 `find` 命令，应列出这一条；总表的“待裁决”视图也应出现它。
5. 删除该文件。

第 2 步失败通常是 YAML 转义问题，回到第三节的书写硬规则逐值检查。
